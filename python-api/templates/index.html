This is the machine learning service of the Prefect of Discipline Management System. It helps the Prefect of Discipline act early on student behavior and review complaints faster, using the two models below.

Models

Early Intervention Violation Predictor

Logistic Regression

Purpose

Estimates how likely a student is to commit the same violation again, so the Prefect of Discipline can step in before it happens.

  • Looks at how often the student committed the violation before and how recently.
  • Explains which factors raised the risk.
  • Suggests an intervention to follow up with the student.

INInput

Violation typeThe violation being assessed, e.g. "Unexcused Tardiness Or Absence".
Past repeat countHow many times the student committed this same violation before.
Recent countHow many of those happened in the last 90 days.
Months since lastMonths since the student last committed it.
Violation typePast repeatsRecentMonths since last
Unexcused Tardiness Or Absence321

OUTOutput

Prediction1 = likely to repeat the violation, 0 = unlikely.
InsightsPlain-language reasons behind the result, including the estimated repeat probability.
RecommendationSuggested interventions for the Prefect of Discipline to follow up with.
PredictionExample insight
1 · Likely to repeatStudent has repeated this violation before (3 times). This increases risk.

Complaint Context Analyzer

Word2Vec + cosine similarity

Purpose

Reads the description of a complaint and suggests which of the school's violations it most likely refers to.

  • Understands the meaning of words, not just exact matches.
  • Ranks the closest violations from strongest to weakest match.
  • Helps the Prefect of Discipline classify complaints consistently.

INInput

Complaint textThe complaint's description, written in plain English.
Example complaint
The student was caught leaving the campus during class hours without permission.

OUTOutput

ViolationA violation from the school's list that matches the complaint.
SimilarityHow close the match is, from 0 to 1.
StatusHow strong the match is, set by the similarity thresholds below.
